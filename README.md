# AbyssCraft 🌊🧱
*A deep-sea survival mashup of Minecraft: Java Edition and Barotrauma.*

## ⚓ The Vision
AbyssCraft transforms the Minecraft experience into a terrifying journey into the crushing depths. Instead of just building a base, you must build a pressurized submarine to survive an abyss filled with Barotrauma's physics, leak systems, and monsters.

## 🛠️ Core Mechanics
- **Pressure System:** The deeper you dive, the higher the atmospheric pressure.
- **Hull Integrity:** Blocks have different pressure ratings (e.g., Glass = Low, Obsidian = Extreme). If your hull rating is lower than the current depth's pressure, your base will start to groan and crack.
- **The Flood:** Hull breaches cause water to leak into your base, forcing you to fight the flood to stay alive.
- **Barotrauma Integration:** Real ambient sounds and monster logic from Barotrauma are mapped onto the Minecraft world.

## 🚀 How to Install (Manual Method)
Since the automated One-Click install is currently blocked by some antivirus software, follow these steps to play:

1. **Install Fabric Loader:** Download and install the latest Fabric Loader for Minecraft 1.21.1 from [fabricmc.net](https://fabricmc.net/).
2. **Add the Mod:** Place the `abysscraft-0.1.0.jar` into your `.minecraft/mods` folder.
3. **Launch:** Start Minecraft using the Fabric profile.
4. **Dive:** Build a base, dig deep, and try not to let the ocean in.

## 📊 Technical Specifications
- **Host Game:** Minecraft: Java Edition 1.21.1
- **Companion Game:** Barotrauma (for assets and logic)
- **Mod Loader:** Fabric
- **Source of Truth:** Sheet-driven development (materials, depth zones, and leak logic).
